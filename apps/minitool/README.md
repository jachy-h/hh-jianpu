# 哈哈简谱 · 随身谱本

只读播放共享内置曲谱的小红书 H5。首版提供分类选曲、谱面、高亮、变速、节拍器、0/4/8 预备拍、A/B 小节循环与双声部静音。

在仓库根目录执行（CI 使用 pnpm 9.15.9，本地启动使用当前已安装版本）：

```sh
pnpm dev:minitool
pnpm build:minitool
pnpm audit:minitool
pnpm package:minitool
```

H5 开发地址是 `http://127.0.0.1:5174`；Web 为 `pnpm dev`，地址 `http://127.0.0.1:5173`。同时开发使用 `pnpm dev:all`，共用一组共享包监听。端口占用时可用 `pnpm dev:minitool --port 5184`；按 Ctrl+C 会停止本次开发任务。

正式包位于 `artifacts/hh-jianpu-minitool-v0.8.4.zip`，校验摘要在同级。不要直接压缩本目录或使用 Web 网站 dist。

`pnpm probe:minitool` 构建独立音频实验；`node scripts/package-minitool.mjs --probe` 打包实验。实验用于确认容器中的音频激活、长音、停止和再次播放。开发服务器的 `/tests/audio-validation.html` 提供真实 OfflineAudioContext 持续/变速渲染检查，`/tests/responsive.html` 提供固定尺寸布局检查，均不包含在生产包中。

客户端满足条件时使用小红书 Storage 保存资源 ID 和偏好，旧版回退浏览器存储；不保存资源源码或个人曲谱。平台读失败时本次禁用偏好写入，避免覆盖尚未读出的既有数据。源码维护在 `packages/score-library/resources/scores`。

静态包校验和普通浏览器检查不能替代容器验收。请将同一 ZIP 上传创服平台，在平台模拟器、Android 真机扫码、iOS 真机扫码分别验证完整流程；Chrome 61 兼容性与真机性能在未实测前仍标为未实测。

播放页根据阅读宽度，使用单行或双行网格展示 BPM、节拍器、0/4/8 预备拍及双声部开关；所有操作完整可见，不使用横向滚动。BPM 使用带渐密刻度、平滑指针与节拍光点的节奏表盘，只从弧线上按下才能拖动，点击中央数字可精确输入；预备拍使用无 / 4 拍 / 8 拍方块选项。横向阅读旋转整组界面，原生安全区先在物理视口预留。

交互配置位于 `src/config.ts`：`followResumeDelayMs` 默认 2000，播放中手动浏览后闲置达到此时间恢复跟随，设为 0 可关闭。点击背景高亮于 0.8 秒内淡出。

节拍器使用参考 Cat typing 画面重绘的包内 SVG，由真实拍点回调触发敲击。猫咪允许向上超出操作栏约 39px，整个 SVG 矩形（包括透明留白和上浮区域）可点击切换节拍器；关闭 / 暂停时静止，预备拍也可驱动动画。无需外部 Lottie 资源或运行时。

操作顺序为：节拍猫 → 速度 → 播放 / 停止 → 预备拍 → 声部 → 循环。窄屏循环选段居中浮在工具栏上方，宽屏放回栏内。

播放页的「发笔记」会生成 900×1200 的暖白朱红练习卡，包含「哈哈简谱」品牌、曲名、调号 / 拍号 / 原谱速度及开头完整行的真实曲谱节选（单声部两行、双声部一组）并打开小红书笔记编辑页，用户可以继续编辑或取消。配图以示意高亮和进度条展示动态跟谱，不代表实际播放进度，笔记标题和正文包含「哈哈简谱」。平台发布笔记接口未提供指定曲谱页面的参数，笔记不能保证直接打开对应曲谱。

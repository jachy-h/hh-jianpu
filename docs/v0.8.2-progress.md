# v0.8.2 minitool 实施进度

日期：2026-10-29
状态：开发与静态检查完成，待小工具容器验收

## 已完成

1. 阅读界面改为薄导航、可伸展谱面、紧凑操作栏。移除单独状态行、谱面底部说明和重复标题；调号与拍号保留。共享 ScoreView 新增默认关闭的 compactHeader，web 保持完整页头。
2. 速度直接显示为 `120 BPM`，可直接输入，失焦或 Enter 提交；支持 ±5 调整，限制 40–220，空值与无效输入恢复原速度。Escape 撤销输入。
3. 节拍器、0/4/8 预备拍及双声部开关均直接放在操作栏，保留选段清除和紧凑节拍提示。
4. 删除“跟着谱面，找到自己的节奏”等底部常驻文案。窄屏操作区自然换行，宽屏尽量单行，不固定保留大块底部空白。
5. ReadingViewport 先预留物理安全区，再把导航、谱面、操作栏和错误提示整体旋转；播放按钮与阅读方向一致。视口尺寸变化重新计算逻辑宽高，谱面自行测量可用宽度。
6. 移除设置按钮、展开状态及原设置面板。播放器仍由 App 持有，切换方向不重建播放器；返回列表停止播放。

## 弧形操作与闲置恢复跟随（追加调整）

- minitool `src/config.ts` 新增 `MINITOOL_CONFIG.followResumeDelayMs`，默认 2000ms，0 关闭。只在播放且跟随暂停时启用；滚轮、拖动、键盘及页面操作重新计时，按住拖动期间不恢复，暂停与卸载清理计时器。web 未配置该功能，保持现有手动恢复行为。
- 移除速度输入框和加减按钮，BPM 与预备拍统一使用 `ArcPicker`；分别传入 40–220 连续候选和 0/4/8 离散候选。弧线支持点选、拖动、方向键、Home / End、Escape 关闭及完成按钮。
- 使用 SVG 本地坐标逆变换处理旋转后的指针操作。展开动画及游标过渡尊重系统减少动态效果偏好。
- 操作栏保持单行，极窄屏或多声部控件较多时允许横向滑动；弹层定位于工具栏上方，不受横向滚动区域裁剪。
- minitool 点击反馈改为 800ms 背景高亮淡出；小节使用底色反馈，键盘 Tab 导航保留背景式焦点提示，移除点击后 outline 圈。
- 新增 3 项恢复计时回归（连续活动、持续按住、暂停 / 卸载、自定义时间）和 2 项弧形坐标回归；全量测试、lint、两端构建通过。
- 普通浏览器辅助验证：单行手机工具栏、速度 120→121、横向旋转后点选弧线改变速度、同一预备拍弹层、循环播放手动滚动后闲置恢复（恢复后播放仍继续）。完成检查后停止播放并恢复 120 BPM。
- 本节替代此前 ±5 / 数字输入 / 窄屏换行方案。候选 ZIP 已按新交互重建，原生容器与真机验收仍待完成。

### 弧线起手与预备拍方块（交互修订）

- BPM 仅在首次按下命中弧线 / 端点 16px 触摸容差时启动拖动；从数字或空白处起手再进入弧线不改变速度。已启动的拖动保留指针捕获，可继续拖出弧线调整。
- 中央数字提供独立精确输入：Enter、失焦或完成提交，Escape 撤销；整数范围 40–220，空白和非法输入保留原值。数字输入与 SVG 拖动区分离，旋转后仍使用本地坐标。

- minitool 16 项测试、lint、构建与候选包静态审计通过；增加弧线起手命中及精确输入回归。
- 普通浏览器验证了留白起手无变化、弧线上按下更新、精确输入 137、完成提交 120，以及 4 拍选择后立即收起；检查后恢复为 120 BPM / 无预备拍。
- 本修订替代上一节“BPM 与预备拍都使用弧形选择器”的交互，真机仍待验证。

### 猫咪节拍器与操作区重排

- 已通过用户打开的 Chrome 页面观察 [Cat typing 动画参考](https://app.lottiefiles.com/animation/670d762c-11e0-47e0-b8e9-41a8c6b43353)。独立浏览器访问跳转登录，未取得原 Lottie 资源；本次实现为参考画面手绘的 SVG 黑猫 / 紫色电脑，不宣称使用了原文件。

- 通过真实 onBeat 回调增加独立序号，左右爪随拍点交替；同一拍号在循环中再次出现也会更新。动画时长随 BPM 限制在拍间隔内，没有额外的循环计时器。
- 暂停 / 停止重置视觉拍点；预备拍可独立驱动动作。关闭时弱化图形，减少动态效果时停用位移，只保留状态提示。

### 操作顺序、循环浮层与猫咪点击区域

- DOM 与宽屏视觉顺序统一为：节拍猫 → 速度 → 播放 / 停止 → 预备拍 → 声部 → 循环。窄屏按该顺序换为两行。
- 窄屏循环选段居中浮在操作栏正上方，底边与操作栏保持 8px 间距，宽度受限以避开左侧猫咪；宽屏恢复栏内正常布局。
- SVG 增加透明命中矩形，整个图形矩形（包含上浮区域与透明留白）均通过父按钮切换节拍器，避免多重 click 处理。禁用时不接收图形点击。
- 320px 浏览器检查：循环提示中心与操作栏中心均为 x=160，提示完整位于栏上方；点击 SVG 透明角落 (13,446) 可以关闭 / 开启节拍器，未改动选段。
- 600px 浏览器检查：六组操作依次排列，循环选段位于栏内；工具网格宽 / scrollWidth 均为 584px，无水平溢出。
- minitool 19 项测试、lint、构建与静态审计通过，候选包更新。前文“不接收点击的装饰区域”由本节的完整 SVG 命中区域替代；容器 / 真机触摸仍待验证。

# v0.8.6 计划

日期：2026-10-30
状态：待实施

## Web 节拍猫

- 将 minitool 节拍猫用于 Web，复用或提取平台无关的展示组件，采用 Web 的节拍器控制与实际拍点；避免多个组件争用 Player 的单一拍点回调。
- 保留节拍器开关、预备拍、暂停、停止及减少动态效果支持，检查键盘操作、移动端布局和播放时节拍同步。

## v0.8.5 未完成事项

- 跨端谱面浏览器验收：编辑定位、手动滚动、闲置恢复、暂停高亮、反复跳转、双声部和多段歌词。
- 两种音频运行时的共同契约测试及真实浏览器音频：长音变速、预备拍取消、循环边界、同音重奏、静音、初始化失败和中断。
- 为 minitool 加入加载中返回/切谱、预备拍切换和分享返回的行为回归，再拆分播放器编排；清理未使用的偏好存储并测试每次打开重置和曲间隔离。
- 分享图片超时和迟到请求的组件级测试，完成平台模拟器、Android 和 iOS 分享成功、取消、失败验收。
- 统一发布入口和独立产品版本策略，生成含 commit、产品及共享包版本、曲库摘要和 ZIP SHA-256 的发布清单；加入打包审计门禁并在干净环境验证。
- 更新架构说明和能力矩阵；核实 Web 后台播放策略、core 内部依赖方向，以及候选 ZIP 在真实容器中的安全区、方向、触摸与音画同步。
- 定义谱面速度、实际播放速度和练习倍率的契约并核查 220/240 边界；评估 Web 阅读模式、共享谱面节选导图及评论快照恢复。
- 测量曲库增长对包体和长谱性能的影响，核查资源来源、署名和分享授权。

具体实施范围和优先级在开始时结合 v0.8.5 的实际进展确认；v0.8.3 评论恢复仍须先核实平台快照接收契约。

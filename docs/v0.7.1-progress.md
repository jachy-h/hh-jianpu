# v0.7.1 实施记录：上下双声部联谱

日期：2026-10-26
状态：S5 基础双声部已实现并通过自动化检查及本地浏览器交互验证；进入 0.7.1 发布流程（关联 issue #3）。

## 已完成

- `Q[upper]` / `Q[lower]` 与兼容别名 `P[...]`：两声部独立解析，保留源码位置、各自 Beam / Slur / 装饰音状态，逐声部校验拍数和小节数。
- 可选的 `声部：upper=旋律, lower=伴奏` 展示名称；`C[upper]` / `C[lower]` 分别沿所属声部的有效普通音符顺序绑定歌词。旧单声部与全曲歌词规则不变。
- `Score.measures` 保持主声部，`secondaryVoice.measures` 存储下声部；统一声部访问及四分音符拍时值辅助函数。
- 上下行按共享起拍点布局，大括号连接、共同小节线横坐标、整组换行；上下行边界和歌词共同决定行高，字号变化参与间距计算。
- 各声部独立调度后汇入共同时间轴，分别使用音源；支持静音、共同小节选段及循环、倍率、倒计时、暂停恢复和同时高亮。选段持续音入口状态按声部隔离，结束时刻取最晚事件。
- 编辑器识别声部标记，点击下声部小节定位其源码；编辑滚动能定位上下行的小节。
- 移调、序列化、保存、备份与恢复保留两个声部和既有分组；双声部诊断未修正时阻止播放与移调。
- 增加首页「上下双声部」示例，更新在线帮助、语法指南、README 与架构说明。
- 修复无空格 Beam 中八度后缀被后一个音符重复当作前缀读取的问题，避免低八度移调往返再次降八度。

## 验证结果

- `pnpm lint`：通过。
- `pnpm build:core`：通过。
- `pnpm test`：Core 265 项、Web 30 项全部通过，共 295 项。
- `pnpm build:web`：通过；保留既有 Browserslist 数据陈旧和大 chunk 提示。
- 核心新增回归：两声部同时起拍；3 个 4/4 小节、BPM 120 的总长为 6 秒；循环入口的同音持续音隔离；不同字号下拍点和小节线对齐；缺失/欠拍诊断；旧谱连续 Q/P 顺序；移调与源码往返；倚音/Beam/Slur 保留。
- Web 新增回归：相同编号的 Slur 在上下行隔离；双声部保存、导出备份、导入恢复与加载；独立静音操作；错误曲谱阻止播放。
- 音源 mock 回归：同拍一次返回两个活动索引；静音保持共同循环长度；暂停后恢复两声部持续音；双声部静音设置不使旧单声部隐式静音。
- 本地浏览器：打开双声部示例，检查普通/超大字号联谱；从上行起点与下行终点选择共同循环区间；播放、单独静音/恢复伴奏，观察上下行同时高亮及贯穿指示线；未捕获到音频运行错误。自动化与浏览器操作不能代替用户对实际扬声器音质、平衡的试听。

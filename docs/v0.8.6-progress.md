# v0.8.6 进度

日期：2026-10-30
状态：进行中

## 已完成

- 将小工具节拍猫提取到共享 `score-view`，两端复用同一图形和动画。Web 使用原节拍器的唯一拍点回调驱动动作，预备拍使用同一回调，暂停和停止后静止；支持减少动态效果和键盘焦点。
- Web 点击节拍猫切换节拍器时先停止播放，再设置下一次播放的开关状态；原速度滑块保留。
- 移除 minitool 已不再使用的偏好存储实现及对应存储测试，将练习设置类型与默认值移至 `practice.ts`；选曲仍按谱面速度重置。
- 清除分享请求清理时的 React Hooks lint 警告。
- Web 操作区新增默认勾选的「按源码换行」；关闭后谱面按可用宽度自动排版。节拍猫支持鼠标或触摸拖动，键盘聚焦后方向键可移动，拖动不会触发节拍器开关，位置限制在视口内。

## 验证

- 全仓 lint、测试、Web 构建、minitool 构建、依赖边界检查与 minitool 静态审计通过；共享曲库 16 首解析与调度检查通过。
- 构建提示本地依赖与 lockfile 不同步、Browserslist 数据陈旧和 Web 大 chunk。
- 尚未进行 Web 实际浏览器的节拍猫布局、操作和音画同步验收，也未进行小工具容器及真机验收。

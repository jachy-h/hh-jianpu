## 架构与文件

- `packages/core`：平台无关的语法、布局、音乐时间与共享播放编排；声明文件不泄漏 Tone、React 或小红书类型。
- `packages/score-library/resources/scores`：唯一资源源目录；构建期生成静态 ESM 与声明。应用使用 workspace 公共入口，不读取另一个应用目录。
- `packages/score-view`：受控 React SVG 组件与配套样式，不读取 Web store、路由或持久化。
- `apps/web/src/adapters/audio`：Tone 时钟、钢琴/合成音和输出混音；共享 Player 继续负责音乐规则。增加 Transport 实例所有权，第二个实例不能停止正在使用它的实例。
- `apps/minitool`：原生 Web Audio 适配、100ms 前瞻/25ms 唤醒时钟、客户端桥接/偏好和只读练习页面。音频中断、页面隐藏和 pagehide 会停止播放。
- `scripts/check-boundaries.mjs`：导入、re-export、动态导入、包依赖和配置路径边界检查。
- `scripts/validate-library.mjs`：共享内置曲谱解析与播放事件校验。
- `scripts/audit-minitool.mjs` / `package-minitool.mjs`：文件白名单、根入口、相对路径/资源存在性、ES2017 经典脚本、禁用调用、依赖清单、Base64、ZIP 体积/CRC 与解压回读检查。
- `scripts/dev.mjs`：共享包/资源开发监听；无效 JSONC 修复后可重新生成，不因一次生成错误结束监听。
- API 迁移、构建与模块职责见 [共享模块说明](architecture/v0.8.0-shared-modules.md)；资源维护见 [曲谱库说明](score-library.md)。

## 实现取舍

为保留既有播放边界的回归保障，Player 继续采用共享的 class 编排，未整体替换为全新的纯 reducer；高亮/恢复持续音选择与 Scheduler 为纯函数，具体音频、时钟及预备拍计时均通过 Runtime 注入。这是对计划中“纯状态转换输出命令”的实现收敛，避免本版同时重写音乐语义；两端没有各自维护第二套音乐规则。后续若进一步纯化编排状态，可在相同 Runtime 契约与回归 fixture 下逐步进行。

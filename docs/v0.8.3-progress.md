# v0.8.3 实施进度

日期：2026-10-30
状态：已实现发布笔记；平台验证待完成

## 已完成

- 按需求调整为使用 `postNote`，在播放页横向阅读按钮旁增加「发笔记」。
- 生成包含曲名的分享卡片，将图片、标题和正文带入笔记发布页；用户可编辑、发布或取消。重复点击受到保护，接口不可用和失败时显示提示，分享前停止播放。
- 小工具测试 22 项、构建与 lint 通过。打包静态审计及 ZIP 回读通过；小工具版本已更新为 v0.8.3，尚未执行正式发布。全项目 lint、core 构建、测试和 web 构建在切换方案前通过。

## 待验证与限制

- [平台文档 §3.3](https://miniapp-sandbox.xiaohongshu.com/minitool/doc#s3-3) 的 `postNote` 没有指定打开曲谱页面或携带快照的参数。发布的图片和文案标明曲名，但不能保证从笔记自动打开对应播放页；原计划的自动跳转尚未实现。
- 尚未在创服平台模拟器、Android 真机和 iOS 真机验证发布、取消、异常和窄屏布局；普通浏览器不能替代容器验收。

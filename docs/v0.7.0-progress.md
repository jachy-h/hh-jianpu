## 实施记录

### 2026-10-26

- 创建进度跟踪并开始实施。
- 修复移调键偏移重复计算；序列化补回自定义元信息和歌词；笛子指法适配按当前调号和临时升降号计算最低实际音高。
- 修复文档化语法未生效/静默截断：裸旋律默认值、`'1` 和 `.1` 前置八度、`P` 旋律别名、休止符附点、超量减时线与重复附点诊断。
- 编辑保存现在绑定触发时的曲谱 ID；切换文档时先提交待保存修改；输入即时写入恢复草稿，解析独立为 300ms。
- 曲谱文件改用 ID 命名、目录同步串行化；manifest 限定应用可删除文件范围。
- 增加版本化 JSON 备份导入导出；ID 冲突时保留现有谱并创建独立导入副本；manifest 增加删除墓碑，防止删除失败后扫描复活曲谱。
- 曲谱列表增加标题搜索、复制；重命名同时更新源码标题。
- 编辑器保存失败时提供重试入口。
- 解析错误计数可点击循环跳转到源码位置，并选中错误范围。
- 刷新启动时若恢复草稿比其绑定的曲谱记录更新，则按绑定 ID 回写曲谱库，避免最新编辑只停留在编辑器草稿中。
- 旧标题命名文件扫描合并后，自动补写稳定 ID 文件和 manifest；保留旧文件作为迁移恢复副本。目录切换/迁移失败可显示同步错误。
- 播放调度事件补充拍数坐标；音符时值、延迟与节拍器都以 Transport ticks 调度，使 BPM 变化沿同一拍数时间轴生效。秒坐标继续保留供既有 API 使用。主音源改为最多 8 声部，容纳跨循环边界的 release 尾音。
- 文件系统备份增加独立状态订阅；编辑器显示目录备份中/成功/失败，目录权限丢失提示重新授权，并可重试当前曲谱库同步。
- 页面 `pagehide` 时同步提交尚未触发自动保存计时器的编辑，确保本地浏览器存储先于页面卸载落盘。
- 修正“导出备份”只读取已保存列表的问题；现在导出时会将当前编辑内容按现有曲谱 ID 更新，或作为独立草稿加入备份，覆盖本地保存失败时的恢复路径。
- 目录恢复会校验备份曲谱结构；同一 ID 的浏览器与目录内容冲突时，将较新内容保留在原条目、较旧内容另存为独立冲突副本，并在曲谱库提示副本数量，避免静默覆盖造成一份编辑丢失。
- 实现按小节闭区间的循环选择；预览中点击小节设置起点和终点，播放器重播选定范围。播放段抽取为纯函数，保留小节边界和拍数坐标；跨循环边界的延音截断，起始倚音/波音保留相对时序。
- 选段重复由 Transport 原生循环点管理，避免反复调度回调在重复边界产生同时间振荡器启动。
- 预热倒计时改由节拍器每拍回调更新，不再另设固定 BPM 的 UI 间隔计时器；预热后续拍按最新 BPM 重新排程，取消时通过代次令牌阻止尚未完成初始化的旧预热任务复活。
- 播放或节拍器预热启动失败时，在编辑页显示错误原因提示和重试入口；停止后清除旧播放错误。
- 调度回归新增小节归属、段落闭区间和跨界延音截断覆盖。
- 预览改为观察自身容器宽度，字号进入 core 布局参数。
- 更新语法入门说明及在线帮助表格。
- 上述为前一阶段的待办，本次继续实施已完成实现及自动化覆盖；真实环境限制见文末。

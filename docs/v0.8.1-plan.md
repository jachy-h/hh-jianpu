# v0.8.1 计划：小工具连续排版与独立展示页

日期：2026-10-29  
状态：规划，待实施  
前置版本：v0.8.0

## 1. 目标

1. minitool 可忽略源码换行，按实际可用宽度安排小节，减少源码短行造成的留白。
2. 拆分列表页与展示页，让播放时的主要空间用于谱面。
3. 展示页提供竖向 / 横向阅读切换，切换时保持播放进度、选段和练习偏好。

## 2. 共享布局参数

在 core 的 `LayoutConfig` 增加 `respectSourceLineBreaks?: boolean`，默认按 `true` 处理；共享 `ScoreView` 暴露并透传同名属性。minitool 传入 `false`，web 沿用默认行为。

- `true`：源码的 `lineBreakBefore` 参与换行，宽度不足时继续自动拆行。
- `false`：忽略源码换行边界，依次累加小节实际所需宽度，放不下时换行。
- 单声部 `layout.ts` 与双声部 `duet-layout.ts` 同时支持；双声部仍统一决定每行包含的小节并对齐拍点。
- 显式指定的 `measuresPerLine` 继续作为数量上限，与源码换行参数独立；minitool 默认不传数量上限。
- 保留音符、歌词、反复记号所需空间，不修改 AST、源码或音符索引。

这能避免“仅因源码换行，一小节独占一行”，但内容过宽的小节仍可能单独成行。v0.8.1 先采用顺序装入策略，不承诺消除所有末行孤节，也不通过压小字号强行塞入。

涉及文件：

- `packages/core/src/renderer/layout.ts`
- `packages/core/src/renderer/duet-layout.ts`
- `packages/score-view/src/ScoreView.tsx`
- `apps/minitool` 展示页

## 3. 列表页与展示页

继续保留一个 `index.html`，通过 React 状态切换两个视图。

| 页面 | 内容与行为 |
| --- | --- |
| 列表页 | 分类、曲谱列表；点击曲谱进入展示页；首次打开停留列表，可标记上次选择 |
| 展示页 | 精简顶栏（返回、曲名、方向切换、设置）、可滚动谱面、紧凑播放栏 |
| 练习设置 | 在展示页按需打开面板，容纳速度、节拍器、预备拍、声部静音；默认收起 |

播放器及练习状态保留在共同父层或独立 hook，避免展示组件重排、设置开合或方向切换时重新创建音频实例。

- 点击曲谱只进入展示页，由用户点击播放开始发声。
- 返回列表时停止播放并取消预备拍，恢复列表分类与滚动位置；再次进入同曲保留本次选段，切换曲谱清空旧选段与高亮。
- 展示页标题与 SVG 标题避免重复占用空间；必要时给共享组件增加默认兼容的标题显示选项。
- 播放栏固定在展示页可用区域内，为谱面预留遮挡补偿；设置与错误提示在横向模式仍可操作。
- 页内返回按钮必须可用；宿主返回键仅在公开契约允许接管时接入，不假定能拦截原生退出。

建议拆出 `CataloguePage`、`ScorePage`、`PracticeSettings` 与播放会话 hook，具体以实现时职责划分为准。

## 4. 横竖向展示

2026-10-29 已查看[小工具在线能力文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)。当前公开接口未提供强制横竖屏或方向锁定；`requestFullscreen` 明确禁用。因此采用 CSS 页内阅读方向切换，实施前再次核查在线契约。

- 默认竖向阅读，按钮切换为横向阅读，再次点击恢复。
- 按窗口尺寸与目标方向决定是否旋转：尺寸方向已匹配时不额外旋转，避免实际横屏后再旋转一次。
- 需要旋转时，对整个展示页容器进行 90° 旋转与定位，交换逻辑宽高；谱面、控件和弹层使用同一坐标体系。
- 使用旋转后的逻辑宽度重新布局 SVG，不仅旋转或缩放旧谱面；检查共享组件现有 1100px 宽度上限是否限制有效屏幕利用。
- 保留原生按钮与安全区占位，将可用区域映射到阅读坐标后计算四侧留白；视觉旋转不会旋转宿主按钮。
- 容器内负责滚动；检查播放跟随的 `scrollIntoView` 在旋转后的行为，必要时按谱面行坐标滚动，避免滚动整个宿主页面。
- 切换后优先恢复到当前播放小节；未播放时锚定正在阅读的小节，避免跳回谱首。
- 监听窗口尺寸变化并重算布局；以尺寸为依据，不依赖设备朝向传感器。
- 方向偏好先保留在本次会话；返回列表解除展示页旋转，重新进入按本次选择恢复。

“横向阅读”描述页面内的显示效果，不承诺改变手机系统方向。触摸命中、长谱滚动、安全区与连续播放必须在真实小工具容器中验证。

## 5. 实施顺序

1. 增加布局参数、共享组件透传及单 / 双声部回归。
2. 拆分列表页与展示页、收拢设置，保持播放会话生命周期稳定。
3. 实现方向切换、逻辑尺寸重算、旋转滚动和安全区映射。
4. 完成布局与交互检查，运行项目质量门禁、小工具审计并打包候选 ZIP。

## 6. 验收

- 相同宽度下，web 默认保留源码边界；minitool 可把源码多行的短小节合并到同一显示行。
- 单 / 双声部、多段歌词、密集音符、反复与换气符在两种参数下正确布局，双声部拍点对齐。
- 从列表选曲、播放、返回、再选曲的状态正确；预备拍取消与切谱不留下声音或旧高亮。
- 展示页不常驻分类选择和大块说明；设置收起时谱面使用顶栏与播放栏之间的可用空间。
- 竖向 / 横向反复切换不重启播放、不重复发声，不丢失速度、选段及静音状态。
- 覆盖 320 / 390px 窄屏、横屏低高度、平板，以及长曲滚动、A/B 点击和多段歌词；切换后控件可见可点，谱面底部无遮挡。
- 按项目规范运行 lint、core 构建、测试、web 构建，以及 minitool 构建、审计和打包。
- 普通浏览器仅用于辅助检查；候选 ZIP 需在创服平台模拟器、Android 真机扫码、iOS 真机扫码验证，分别记录结果，未验证项保留待验状态。

本计划阶段仅新增文档；版本号、CHANGELOG 和正式发布在后续发布流程处理。

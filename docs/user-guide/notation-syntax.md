## 元信息与默认值

推荐以两个 `---` 包裹元信息。支持中英文冒号；基础字段为标题/title、调号/key、拍号/time、速度/tempo。其他中英文字段作为扩展元信息保留。`#` 和 `//` 仅能在元信息块中作为整行注释；旋律中 `/` 始终表示减时线，`#` 表示升号，不支持行尾注释。

```jianpu
---
标题: 小星星
调号: C
拍号: 4/4
速度: 120
作曲: 莫扎特
// 元信息注释
---
Q 1 1 5 5 | 6 6 5 - |
C 一 闪 一 闪 亮 晶 晶
```

也接受只含基础字段的旧式头部（不写 `---`）。裸旋律使用 C 调、4/4 拍、速度 120。速度目前按每分钟四分音符数播放；6/8 等拍号只改变小节时值校验，不把速度解释为附点四分音符数。

## 音符与标准顺序

`1` 至 `7` 表示 do 至 si，`0` 表示休止。标准音符顺序为：装饰音前缀 → 升降号 → 音级 → 八度 → 减时线 → 附点 → 奏法标记。修饰符与音符紧邻书写。

| 符号 | 含义 | 示例 |
|---|---|---|
| `\|\|` | 结束线，显示为一条黑线 | `1 2 3 4 \|\|` |
| `:\|\|:` | 结束上一反复段并开始下一反复段；黑线两侧各两个反复点 | `1 2 3 4 :\|\|: 5 6 7 1 :\|\|` |
| `#` / `b` | 升/降半音，写在数字前 | `#4`、`b7` |
| `'` | 升一个八度，标准写在数字后 | `1'`、`1''` |
| `,` | 降一个八度，标准写在数字后 | `5,`、`5,,` |
| `/` | 八分音符 | `1/` |
| `//` | 十六分音符 | `1//` |
| `.` | 单附点，原时值乘 1.5 | `1.`、`1/.`、`0/.` |
| `!` | 短顿音；保留原占拍，默认只发声原时值的 1/4，显示为音符上方的实心倒三角 | `5!`、`5/!`、`5'!` |
| `-` | 将前一个发声音延长一个四分音符时长 | `1 - - -` |
| `v` / `V` | 换气，不占时值；紧邻小节线或反复记号前后时显示在线正上方，不占横向间距 | `1 v \| 2`、`1 \| v 2`、`\|\|: v 1 :\|\|` |

兼容读取前置高八度 `'1`、前置低八度 `.1`，以及减时线后的八度 `5/,`。输出统一使用后置八度。`1.` 是附点，低八度应写 `1,`；`1 -` 的时长是两个四分音符，与 `1.` 不等价。

基础音符和休止是四分音符；4/4 中 `1` 为 1 拍、`1/` 为半拍、`1//` 为四分之一拍。其他拍号以分母为单位计算拍数，例如 6/8 中 `1/` 为 1 拍、`1` 为 2 拍。暂不支持三条及以上减时线和双附点，会报告诊断；`_` 不是减时线。

`!` 是本站的短顿音播放约定：音符按原时值占拍，音源发声时长为该时值的 1/4，剩余时间静默；例如四分音符 `5!` 占一拍但发声四分之一拍。比例用于确定性播放，实际演奏可随速度和风格变化。当前短顿音不支持用于倚音、波音主音、圆滑线组或延长线组合；解析会显示诊断。

```jianpu
---
拍号: 4/4
---
#4'/. b7,// 0 1 2 |
```

## 小节、空白与 Beam

`|` 分隔小节，两侧空格可省略；行尾的小节线也可省略。每小节总时值应符合拍号，否则显示诊断。换行控制预览分行，但不自动结束小节。预览优先遵循源码分行，不限制每行固定小节数；仅在音符、歌词或字号所需宽度超过容器时，在小节之间追加换行，并保留后续源码换行。单个小节过宽时可横向滚动查看。行尾 `|v` 的换气符归属前一小节，不影响下一行的分行位置。

音符可连续书写。空格、Tab 和换行分隔 Beam 分组：相邻且没有空白的八分或十六分音符/休止符共享减时线，也允许混合时值。小节线自动断开 Beam。

```jianpu
Q 1/2/ 3/4/ 5/6/ 7/1'/ |
Q 1//2//3/ 0/ 4/ 5 6 |
```

## 圆滑线与延长

`(1 2 3)` 表示 Slur，支持跨小节。括号必须配对；嵌套括号目前按最外层分组，不表示多层圆滑线。Beam 是减时线连接；Slur 是演奏分组；`-` 是同音延长，三者含义不同。本版没有新增显式 Tie 语法。

```jianpu
(1 2 3 4 | 5 6) 7 1' | 1' - - - |
```

## 装饰音

倚音用 `^` 前缀，必须带减时线：`^4/` 为长倚音，`^4//` 为短倚音。倚音不占独立节拍，播放时从主音符借用时间；不消费歌词。可结合升降号和后置八度，如 `^#4'//`。

波音前缀为 `~`（单波音）、`~~`（复波音）、`~.`（下波音）。波音主音仍占原本时值并消费一个歌词。

短顿音后缀 `!` 可与升降号、八度、减时线和附点组合。示例中的连续八分音符各自保留半拍占拍，只发声八分音符时值的四分之一：

```jianpu
5! 5! 5/!5/! 5! |
```

```jianpu
^4/ 5 ^6// 5 6 7 | ~1 ~~2 ~.3 4 |
C 一 二 三 四 五 六 七 八
```

## 旋律与歌词

行首可用 `Q ` 标记旋律，`P ` 为兼容别名；裸旋律等价。`C ` 开始歌词行。

歌词行按出现顺序合并，再从曲谱第一个有效普通发声音符起分配；不会按相邻旋律块重新绑定。每个字符消费一个音符，空格仅用于阅读。`(多个字)` 消费一个音符，`_` 跳过一个普通发声音符。休止、延长线、换气与倚音不消费歌词，无需为它们添加占位。歌词内 `-` 是普通文字，不能用作延长或占位。当前不校验歌词数量，过多歌词不会显示，过少则余下音符无词。

```jianpu
Q ^4// 1 0 2 - | 3 4 5 6 |
C 我 (爱你) _ 星 光 明
```

以上歌词对应普通音符 `1 2 3 4 5 6`，不为 `^4//`、`0`、`-` 消费音节。

## 诊断与规范回写

无法识别的字符、孤立修饰符、括号不匹配以及超出支持范围的时值会显示源码位置。小节拍数诊断定位整个小节。错误曲谱仍可预览已识别的内容，修复诊断后再用于练习。

移调改变实际音高：上移 N 个半音，播放音高只上移 N 个半音。跨调号边界时保留八度变化。回写保留歌词、扩展元信息、装饰音、Beam 分组、跨小节 Slur 与小节分行；会规范化空白和元信息格式，不保留注释原文。

## 反复记号

`||:` 自身划分小节并开始新的反复小节，前面无需额外添加 `|`；`:||` 放在小节终点。反复段总共演奏两遍，再继续后面的音乐；谱面只显示原写法，不复制小节。只有后反复时从曲首重复一次，普通 `|` 和 `||` 不触发反复。

```jianpu
||: 1 2 3 4 | 5 6 7 1' :|| 1' - - - |
```

播放小节顺序为 `1 → 2 → 1 → 2 → 3`，BPM 120 时音乐时间为 10 秒，不含预备拍和释放尾音。播放高亮跟随原谱，暂停恢复和变速保留当前遍次，停止后重新开始从第一遍演奏。预备拍仅在首次开始时执行。

- 支持单小节反复、多个顺序排列的反复段，以及相邻段边界 `:|| ||:`。也可合写 `:||:`，结束上一段并开始下一段；同一行显示为一条黑线，两侧各两个反复点，跨行则分别显示后反复和前反复。
- 前反复必须有后反复。嵌套反复、空反复段，以及房子/跳房子、指定次数、D.C./D.S. 暂不支持，须修正源码位置诊断后再播放。
- 双声部须在对应边界写一致的反复符号，两个声部按同一顺序演奏。
- 完整 A/B 选段优先，按书写顺序循环所选小节，暂不展开内部反复；清除选段后恢复谱面反复。
- 保存、JSONC 下载与备份、移调和源码回写保留反复符号。


## 上下双声部联谱

上下两行同时演奏，使用 `Q[upper]` 和 `Q[lower]` 指定主旋律、伴奏。对应小节共享拍点、小节线、调号、拍号及速度；同一声部后续的行继续追加到该声部。预览会将上下行一起换行并显示联谱大括号。

```jianpu
---
标题：双声部练习
调号：C
拍号：4/4
速度：120
声部：upper=旋律, lower=伴奏
---
Q[upper] 3/5/ 7/1'/ 1' - | 2/4/ 6/1'/ 2' - |
C[upper] 春 风 吹 过 来 春 风 又 吹 来
Q[lower] 1 0 0 1 | 6, 0 0 2 |
C[lower] 低 音 伴 奏
```

- `声部` 元信息可省略；省略时名称为“旋律”和“伴奏”。声部 ID 固定为 `upper`、`lower`，名称只用于展示。兼容 `P[upper]` / `P[lower]`。
- 双声部模式的每条旋律、歌词行均需标明声部。`C[upper]`、`C[lower]` 分别按各声部的有效普通发声音符顺序分配歌词；休止、延长线、倚音和换气不消费歌词。局部歌词可用 `_` 为此前无词音符占位，目前不按相邻旋律块重新开始分配。
- 两声部的小节数须相等，每小节分别满足拍号。整小节休止用休止符写足时值，例如 4/4 拍写 `0 0 0 0 |`。缺失小节、欠拍或超拍会显示含声部和源码位置的诊断，修正后才能播放或移调。
- 播放条可分别静音上下声部，以便单独练习；静音不改变播放时长。小节选段、循环、变速、倒计时和暂停恢复共用时间轴；高亮可同时显示上下声部的当前音符。
- 旧谱的裸旋律、`Q`、`P` 和 `C` 行保持原有含义，连续旋律行仍按先后顺序演奏。双声部需显式输入，不能混用无标记旋律行。
- 当前支持每声部单音旋律及既有装饰、Beam、Slur；暂不支持叠置和弦、琶音记号或第三声部。单声部旧版本不能正确解释此语法；用支持双声部的版本继续编辑。保存与备份保留完整源码，移调同时处理两个声部。

# 从第一首简谱开始

不用先学会所有符号。先写一段、听一遍，再学需要的写法。

## 三步听到旋律

1. 在首页点击“新建曲谱”，或打开一首示例。
2. 把下面的文字复制到编辑器，曲谱会自动显示。
3. 点击底部的播放按钮。

```text
---
标题: 小星星
速度: 80
---
Q 1 1 5 5 | 6 6 5 - |
C 一 闪 一 闪 亮 晶 晶
Q 4 4 3 3 | 2 2 1 - |
C 满 天 都 是 小 星 星
```

数字表示音符，`|` 分隔小节，`-` 让前一个音多唱一拍。`C` 开头的是歌词行，不写也可以。开头两行 `---` 之间可以改标题、速度，也可以添加 `调号: C`、`拍号: 4/4`。

钢琴首次播放需要稍等加载；加载失败可重试，或切换“原声（合成音）”。

## 先记住这几种写法

以下拍数以 4/4 拍为例，每小节凑满 4 拍。

| 想要 | 这样写 | 含义 |
|---|---|---|
| 写音符 | `1 2 3 4 5 6 7` | 哆来咪发嗦啦西 |
| 停一拍 | `0` | 这一拍不发声 |
| 唱长一点 | `1 -` | 共 2 拍，每多一个 `-` 再加 1 拍 |
| 唱短一点 | `1/`、`1//` | 半拍、四分之一拍 |
| 加附点 | `1.` | 1 拍半 |
| 高八度 | `1'` | 数字后加英文单引号 |
| 低八度 | `1,` | 数字后加英文逗号，不是句号 |

符号用英文输入，音符之间留空格。不写设置时，默认 C 调、4/4 拍、速度 120。6/8 拍中，`1/` 占一拍，`1` 占两拍。

歌词用 `C` 开头，一字对一个音。一个音唱多个字，用括号包起来；某个音不唱词，用 `_` 占位。休止符和延长线不用配词。多行歌词从曲首依次分配，不会在每行旋律下重新起算。

需要升降音、装饰音、反复或双声部时，打开网页帮助“怎么写谱”下的对应条目，或查阅[完整符号说明](./notation-syntax.md)。

找不到符号在哪个键上？打开帮助末尾的“符号速查”，悬停或点选表格中的符号，上方键盘会高亮需要的键。以英文美式键盘为例，`|` 用 Shift + `\`，`#` 用 Shift + `3`；组合写法会显示输入顺序。也可按 Tab 聚焦符号查看。

沿 01 → 06 的方向继续浏览时，键盘先贴紧内容区上方；继续滚动，同一块键盘逐渐平移到正文右侧，并按右侧空白等比例缩小。往回滚动时沿原路径恢复。移动端小屏幕保持上方贴顶，不向右移动。

## 把一首曲子练熟

在底部播放条调整：

- **慢放**：把练习速度调到 0.5×，熟悉后再加速。可选 0.5×～2×，不改原谱速度。
- **预备拍**：选择 4、8 或 16 拍，留时间准备乐器；0 拍直接开始。
- **循环一段**：在预览中先点起点小节 A，再点终点小节 B，两端小节都会循环。选段内按书写顺序播放；清除选段后恢复全曲及谱面反复。
- **暂停与重来**：暂停后接着播放，停止后回到开头。光标不在编辑器内时，也能按空格播放或暂停。
- **看清曲谱**：调整字号；手动滚动后，点“恢复播放跟随”继续自动跟谱。

竹笛新手可从首页“竹笛入门”的练习曲开始。双声部可分别静音旋律或伴奏。

需要移调时，在编辑器选择目标调号或筒音指法，核对后应用。移调会改变实际播放音高，双声部一起调整；会整理谱文格式，不保留注释原文，想留原稿时先下载。

## 保存好，再换设备

编辑内容自动保存到当前浏览器。离开前确认“浏览器已保存”；编辑公共示例会创建个人副本。

| 想要 | 在首页这样做 |
|---|---|
| 留一首曲谱 | 在个人曲谱中点击“下载” |
| 备份全部 | 点击“下载全部曲谱”，保存好下载的文件 |
| 换设备或恢复 | 把文件传到新设备，点击“导入曲谱”，在弹窗中选择或拖入文件 |

下载的是可再次编辑的 JSONC 曲谱文件，导入支持 JSON、JSONC 和备份包。清理浏览器网站数据可能丢失曲谱，记得定期下载备份。

支持的浏览器可通过“更改存储位置”设置本地文件夹备份。“浏览器已保存”和“目录备份已同步”各有状态；保存失败时点击“重试保存”，目录失败时按提示重试或重新授权。重复导入相同曲谱会跳过；内容不同则保留原谱并新增导入副本。遇到“冲突副本”时，核对内容后再整理。

## 遇到问题

| 问题 | 先这样检查 |
|---|---|
| 没有声音 | 检查音量、声部静音和编辑器错误；钢琴加载失败可切换合成音 |
| 小节拍数不对 | 4/4 拍每小节凑满 4 拍，例如 `1 2 3 4` 或 `1 2 3 -` |
| 低音变成长音 | 低音写 `1,`，附点才写 `1.` |
| 歌词错位 | 无词音符用 `_`，休止和延长线不用占位；换行不会重新配词 |
| 想控制换行 | 在小节之间按回车；屏幕放不下时，预览会自动换行 |
| 想上传图片识谱 | 暂未开放，可手动输入或导入曲谱文件 |

更多写法见[完整符号说明](./notation-syntax.md)。文档维护者请参阅[同步更新清单](./maintenance.md)。

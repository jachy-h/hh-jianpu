## 已完成

- Core `LayoutConfig` 增加 `respectSourceLineBreaks`，默认遵循源码换行；单声部与双声部布局均可关闭源码换行。
- 共享 `ScoreView` 透传该参数；minitool 展示页使用自动宽度换行，web 默认行为保持兼容。
- minitool 增加曲目列表入口与独立展示页；列表页以分类分组的可点选曲目卡片呈现，不使用 select，点击曲目直接进入展示页。练习设置可收起，播放栏和播放器生命周期保留在应用父层。
- 增加竖向 / 横向阅读按钮。页内横向阅读在竖屏尺寸下旋转展示容器，设备已处于横屏时按原方向展示；谱面按横向视口宽度重算。
- 保留单 HTML 入口和离线容器适配；未调用全屏或设备方向 API。

## 播放跟随滚动优化

- web 与 minitool 共用的 `ScoreView` 在进入新行时主动平滑滚动，让当前行起点保持在视口上方约三分之一处；谱首和谱尾按可滚动范围限制。同一行内切换音符不重复触发滚动。
- 反复回跳、循环及跨段跳转直接定位；双声部按共同小节所在的联谱行定位。窗口大小或布局变化时重新计算。
- 使用谱面内部逻辑坐标和容器 `scrollTop`，避免外层旋转后的屏幕坐标影响定位；仅滚动谱面内部容器。
- 滚轮、触摸拖动超过 8px、滚动键盘操作暂停跟随；点按小节不再被误判为手动滚动。恢复按钮重新定位当前行。
- web 非播放时的源码定位仍使用谱面行坐标靠顶部定位；系统减少动态效果设置下使用直接定位。
- 验证：新增 4 项滚动计算回归通过；全量 `pnpm test`、`pnpm lint`、`pnpm build:minitool`、`pnpm build:web` 通过；小工具审计通过（237222 文本字节、0 错误、0 警告）。上文候选 ZIP 为此前产物，本次未重新打包。
- 仍待容器 / 真机验证：长谱连续跟随、双声部、循环、手动拖动后恢复及横向阅读。自动化结果不能替代这些交互验收。

- 使用瓷白谱纸、蓝灰页面、深海蓝文字与播放栏、琥珀色播放按钮及节拍，替换原有绿色 / 米色体系。
- 以 CSS 变量管理背景、文字、边框、选中、聚焦、警告和播放状态；当前音符使用深琥珀色，循环选段使用浅琥珀色，已播放音符使用蓝灰色。
- 谱面 SVG 颜色由 minitool 内部样式映射，共享组件及 web 默认颜色保持兼容。
- minitool 构建、lint、静态审计通过；普通浏览器查看列表页和展示页确认视觉效果，容器与真机仍待验收。

# 播放音色（v0.7.4）

网页默认使用教学钢琴，播放条可切换「原声（合成音）」。音色选择独立保存在当前浏览器，不写入曲谱；切换时停止当前播放及倒计时，下次从曲首或选段起点开始。

钢琴使用离线制作的起音＋循环持续段，延长音持续到谱面规定的结束拍点，再进入释放段，不重复敲击。它是适合简谱练习的持续钢琴音色，不采用真实钢琴一直自然衰减的效果。
首次使用按需加载约 2.6 MB 的同域 WAV；加载中可以停止或切换，失败/30 秒超时后可重试。切换释放解码缓冲，切回时可利用 HTTP 缓存。

## 音乐时间与发声方式分离

```
Parser → Scheduler（音高、起止拍点、奏法）
                    ↓
        Player / Transport（noteOn、noteOff、唯一 ID）
                    ↓
        Instrument（采样持续/合成器包络）
                    ↓
          统一混音增益与峰值保护 → 输出
```

- Scheduler 唯一决定实际发声拍数：普通短音保留 90% 门限，长音、延长线与圆滑线持续到规定拍点，短顿音使用 1/4 门限。
- Player 分别在起音拍点和结束拍点发送事件，不把完整时值提前换算为秒；播放中改变 BPM，尚未发生的结束事件随 Transport 改变。
- 每次发声均生成独立 ID，同音重奏、上下声部、反复和循环中的不同轮次不会误释放其他音符。
- Transport 的 loopEnd 边界负责关闭上一轮仍活动的音；不依赖那个 tick 上不会执行的普通 schedule。
- 暂停释放当前发声，继续时依据统一时间轴恢复仍在有效门限内的音。钢琴从持续段恢复，合成音以持续电平恢复，不重放完整起音。
- 选段从延长线或同音连音中间进入时恢复相应持续音，并将结束事件裁到选段边界。

## 开闭原则与代码位置

- `player/instrument.ts` 定义 `InstrumentNote`、`PlaybackInstrument`、`InstrumentBank` 和 `InstrumentDefinition`。
- `noteOn(note, time)` 开始指定 ID，`noteOff(id, time)` 结束该 ID；音源不解释乐谱拍数、不自行读取 BPM。
- `triangle-instrument.ts` 与 `sample-instrument.ts` 各自实现合成/采样，两者均接收 Player 注入的输出节点，不能直接连接扬声器。
- `audio-output.ts` 提供所有旋律声部和节拍器共用的混音输出；普通电平透明，仅对接近满刻度的峰值平滑收敛。
- Web 的 `services/playbackInstruments.ts` 是音色组合入口，注册表同时驱动 UI 和偏好校验；采样路径来自 Web 的 BASE_URL。
- 新增音色只需实现工厂或配置采样与循环点，然后注册；不修改 Parser、Renderer、Player 的音乐时间逻辑。

无参数 `new Player()` 继续使用原合成音，保持 core 调用方式兼容。扩展的音源工厂接口采用新的起止事件契约。

## 钢琴素材制作与响度

保留的原始录音是 Alexander Holm 的 Salamander 钢琴采样（CC BY 3.0），许可和署名见 `apps/web/public/audio/piano/NOTICE.md`。

执行 `python3 scripts/prepare-piano-samples.py` 可以重新生成持续采样，需要系统 ffmpeg，不新增运行时依赖：

1. 从每个音区较早的稳定段取约 0.24 秒的环，低音区起点约 0.3 秒，高音约 0.14 秒。
2. 平滑校准录音的振幅包络，持续段目标 RMS 为 0.22，单独处理瞬态峰值，避免用起音峰值把整个持续段再次压低。
3. 环末尾交叉淡入环起点之前的波形，减小接缝；保持原始起音，输出 44.1 kHz 双声道 PCM WAV。
4. 生成 `src/services/piano-samples.json` 的资源/循环点清单，以及 `public/audio/piano/sustain/measurements.json` 的持续电平、峰值与接缝测量。

运行时每个音符以最近的采样变调，持续环跟随采样播放速率，等待外部 noteOff。文件长度不再限制长音。各音区先分别校准，再通过音色级 -2 dB 增益匹配原合成音；两种音色使用同一混音输出，不再只给钢琴额外限幅。

## 可复现验收

`pnpm lint`、`pnpm build:core`、`pnpm test`、`pnpm build:web` 覆盖类型、构建、资源及调度回归。

启动 `pnpm dev` 后打开 `/tests/audio-validation.html`，点击「运行验收」。该页使用真实 Player、Transport 和 Web Audio 离线渲染，不接触个人曲谱，也不是生产构建入口。提供一拍/四拍、中途变速、同谱钢琴/合成音的试听与 WAV 下载。

自动检查项目包括：

- 一拍与四拍分别结束，四拍持续段末尾仍清晰发声；释放后归零。
- 120 BPM 的四拍长音在第 1 拍后降到 60 BPM，结束时间由 2 秒延长到约 3.5 秒。
- 连续循环产生不同发声 ID，后续轮次仍持续发声；上声部静音不影响下声部。
- C3/C4/C5/C6 的持续电平一致；同谱音色比较完整音符与长音，不再用短旋律 RMS 作为唯一通过标准。
- 暂停恢复、加载竞态、资源失败重试、选段入口持续音和采样循环参数另有单元回归。

离线渲染能检查音频持续、时序与电平，听感仍需通过验收页试听确认，不能仅凭文件名或测试数量认定音色合格。

2026-10-28 最终参数实测：四拍长音在 2 秒收到 noteOff，持续段前后 RMS 分别约 0.17479 / 0.17497，释放后为 0；第 1 拍后减半速度的 noteOff 为约 3.498 秒。C3–C6 持续 RMS 均约 0.1747。同谱九秒文件经 ffmpeg ebur128 测得钢琴 -11.8 LUFS、原合成音 -12.3 LUFS，差约 0.5 LU；同谱 RMS 差约 0.36 dB。真实编辑页长音中的暂停/恢复、停止及音色切换均未报告音频运行错误。
